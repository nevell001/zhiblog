# v1.4.5 (2026-10-11)

本版本包含注册合规、关于页改版、文章管理与多处后台体验修复。

## ✨ 新增与增强

**文章管理**

- **文章回收站**：删除文章改为移入回收站（软删除），后台新增「回收站」入口，可一键恢复或彻底删除；回收站文章保留 30 天，到期由每日定时任务自动彻底删除。文章列表与导出默认不含已删除文章；恢复时若标题已被其他文章占用会拒绝并说明原因（标签关联在回收站期间保留，恢复后不丢）
- **编辑器草稿自动保存**：写文章过程中改动自动保存到浏览器本地（防抖），意外关闭或刷新后重新打开会询问恢复上次未保存的内容；有未保存改动时关闭页面会二次确认
- **文章代码高亮**：前台文章详情页代码块按标注语言高亮渲染，支持 Java、JavaScript/TypeScript、Python、Go、SQL、Shell、JSON、YAML、HTML/CSS 等 15 种常用语言；未标注或未收录语言保持原样，深浅模式统一深色代码底
- **媒体库引用保护**：删除上传文件前检查文章、自定义页面、站点设置、友情链接、用户头像中的引用，仍被引用的文件跳过删除并提示引用来源，避免删掉物理文件导致引用处图片失效

**注册合规**

- **注册页协议勾选**：注册前须勾选同意；文案中的《用户协议》《隐私政策》为链接，点击新窗口打开全文页
- **前台协议全文页**：新增 `/blog/agreement`（用户协议）与 `/blog/privacy`（隐私政策），深浅色适配；正文按 ZhiBlog 实际收集与处理的数据编写（邮箱注册、评论先审后发、邮件通知、LocalStorage 登录态、密码单向加密等），未配置时零依赖展示
- **后台「协议页面」**：博客设置新增页签，两个富文本编辑器分别编辑用户协议与隐私政策，保存后自动清除前台缓存即时生效；数据库内容优先，清空则回落内置标准文本
- **新增设置键**：`blog_setting` 增加 `user_agreement_content` / `privacy_policy_content`，纳入前台匿名设置白名单（`/common/blog/setting`）

**内容与设置**

- **关于页并入页面管理**：`/blog/about` 改由「页面管理」中 `slug=about` 的页面行渲染（标题/内容/SEO 均可编辑），导航「关于」入口随该行「导航显示」开关出现，原固定入口与「关于页面内容」设置项退役
- **页脚备案开关**：博客设置新增「显示备案」（`beian_enabled`），开启且已填写备案号时页脚展示备案信息，备案号默认链接工信部官网
- 访客留言板、友链申请入口、页脚备案显示三个开关的默认值调整为关闭（可在博客设置中开启）

**管理后台**

- **统计页体验统一**：文章/访问/用户三个统计页的 KPI 卡片改用同一组件与排版，数值对齐；各图表面板与列表补齐空状态提示
- **监控页深色适配**：Actuator / Prometheus / Grafana 三个监控页在深色模式下文字与组件配色修复

## 🐛 主要修复

- **文章统计页图表首屏空白**：「分类分布」「热门标签」两张饼图打开页面时不渲染、切换一次主题才出现，改为就绪后再渲染
- **设置单键查询接口取值字段错误**：接口把值放进了消息字段、前端 `data` 恒为空（监控入口地址等读取长期依赖兜底值），改为正确返回 `data`
- **本地裸跑后端读不到 `.env`**：spring-dotenv 按进程工作目录查找 `.env`，从 `zhi-admin/` 目录 `mvn spring-boot:run` 时全部 `${DB_*:默认值}` 静默回退（数据库账号回落 `root`），导致连库失败；改由 `application.yml` 的 `spring.config.import`（`optional:file:./.env[.properties]` + `../.env` 兜底）加载，从仓库根或模块目录启动均可读到

## ⚠️ 升级提示

- 未改表结构（无 schema 迁移，回收站复用文章表已有的 `del_flag` 字段）；已有安装重跑 `sql/00_init_database.sql` 可补齐两个协议键种子与「关于」演示页（`INSERT IGNORE` 幂等，不覆盖已有编辑）
- **关于页有行为变更**：内容改为「页面管理」中的 `slug=about` 行维护，原 `about_content` 设置不再生效。
  - 此前自定义过关于内容的站点：请跑 [`sql/99_fix_about_page_v1.4.5.sql`](../sql/99_fix_about_page_v1.4.5.sql)（幂等）把旧内容搬进页面管理，导航入口与内容均保持不变；
  - 使用默认关于内容的站点：不跑脚本则关于页为空，重跑 00 脚本会得到演示内容；导航「关于」入口由页面管理里该行的「导航显示」开关控制，需要时打开
- **文章删除语义变化**：后台删除文章不再直接抹除，而是移入回收站（前台与列表立即不可见），30 天内可在回收站恢复或手动彻底删除；到期自动清理依赖后端定时任务，升级后需重启后端
- 变更涉及后端（设置白名单、单键查询、文章软删除、媒体引用检查）与前端（注册页、协议页、设置页、关于页、统计/监控页、文章编辑页、媒体库、文章详情页），前后端镜像都需重建：`docker compose -f docker-compose.prod.yml up -d --build`
