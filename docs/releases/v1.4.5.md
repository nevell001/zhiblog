# v1.4.5 (2026-10-04)

本版本主题是**注册合规**：用户注册需同意《用户协议》与《隐私政策》，协议正文内置贴合系统实际功能的标准文本、开箱即有内容，站长可在后台随时自定义覆盖。

## ✨ 新增与增强

- **注册页协议勾选**：注册前须勾选同意；文案中的《用户协议》《隐私政策》为链接，点击新窗口打开全文页
- **前台协议全文页**：新增 `/blog/agreement`（用户协议）与 `/blog/privacy`（隐私政策），深浅色适配；正文按 ZhiBlog 实际收集与处理的数据编写（邮箱注册、评论先审后发、邮件通知、LocalStorage 登录态、密码单向加密等），未配置时零依赖展示
- **后台「协议页面」**：博客设置新增页签，两个富文本编辑器分别编辑用户协议与隐私政策，保存后自动清除前台缓存即时生效；数据库内容优先，清空则回落内置标准文本
- **新增设置键**：`blog_setting` 增加 `user_agreement_content` / `privacy_policy_content`，纳入前台匿名设置白名单（`/common/blog/setting`）

## 🐛 主要修复

- **本地裸跑后端读不到 `.env`**：spring-dotenv 按进程工作目录查找 `.env`，从 `zhi-admin/` 目录 `mvn spring-boot:run` 时全部 `${DB_*:默认值}` 静默回退（数据库账号回落 `root`），导致连库失败；改由 `application.yml` 的 `spring.config.import`（`optional:file:./.env[.properties]` + `../.env` 兜底）加载，从仓库根或模块目录启动均可读到

## ⚠️ 升级提示

- 未改表结构，无需迁移脚本；已有安装重跑 `sql/00_init_database.sql` 可补齐两个协议键的种子数据（`INSERT IGNORE` 幂等，不影响已有自定义内容）
- 变更涉及后端（设置白名单）与前端（注册页、协议页、后台设置页），前后端镜像都需重建：`docker compose -f docker-compose.prod.yml up -d --build`

**完整变更**：`git log v1.4.4..v1.4.5`
