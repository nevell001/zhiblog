# v1.4.3 (2026-10-03)

本版本全部是 v1.4.2 发布之后合入的工作，主题是**一处会让所有注册用户看到管理员界面的权限缺陷**，加上前端设计系统的一次系统性收敛（令牌化、深色模式对比度、公共组件抽取）。

## 🔒 安全与隐私

- **HTML 消毒器加固**：正文白名单里移除 `style` 属性（可承载 `expression`/选择器探测类攻击），`iframe` 从任意域收敛到域名白名单
- **产线依赖漏洞清零**：升级 `axios` 与 `brace-expansion`，修掉产线依赖里报出的高危漏洞
- **404 响应不再回显环境信息**：`GlobalExceptionHandler` 的 404 文案里曾硬编码 `http://localhost:8080/blog`，既把开发地址暴露给外部探测，也在生产域名下给出错误引导；现只回一句「请求的页面或资源不存在」，URI 与异常细节仅留在日志
- **登录链路不再因缺少 User-Agent 空指针**：`UserAgentUtils.getBrowser/getOperatingSystem` 对 null/空串没有兜底，而 `TokenService` 与异步登录日志都直接调用它们 —— 匿名探测请求（无 UA 头）可以让一次正常登录在记录阶段炸掉。现在缺 UA 归一为 `UNKNOWN`
- `ExcelUtil` 的空 `catch` 块补 debug 日志，导出失败不再是无声失败

## 🐛 主要修复

- **注册用户被当成系统用户（本版本最重要的一处）**：`SysUserMapper.insertUser` 的列清单漏了 `user_type`，注册流程设置的 `'01'`（博客用户）被**静默丢弃**，落库拿到 DDL 默认值 `'00'`（系统用户）。于是任何自助注册的人都会在前台看到「管理后台」入口，个人中心按管理员渲染出「写文章」，点进去是 `/admin/blog/article` 404。修复：mapper 持久化该列 + 存量数据补丁 `sql/99_fix_blog_user_type_v1.4.3.sql`；前端同时把 `userType` 默认值从管理员改为普通用户，并按 `user_type === '00'` 门控后台入口与写文章/文章管理，博客用户刷新首页不再连弹 4 条「没有权限」通知，登录页也会先验证残留 token 有效性
- **后台「留言管理」整页 500**：`blog_message` 建表时没有 `create_by`/`update_by`，而 `BlogMessageMapper` 查询了这两列 —— 列表、审核、回复全部抛 `Unknown column`，而公开留言板 POST 从不写这两列，所以前台一切正常，没有任何页面暴露它。补齐列（`CREATE TABLE` + 幂等 `ALTER` 块）
- **博客用户保存不了基本资料**：手机号被当作必填，而注册流程从不采集 —— 改为选填并保留格式校验
- **保存资料后顶栏昵称不刷新**：需要整页刷新才更新，现同步写回 user store
- **头像裁剪偏移**：选框可拖出图片之外、预览与实际提交偏离、旋转后预览丢帧；`120×120` 原图在 `72×72` 容器内从左上角裁剪而非居中
- **邮件「测试连接」不传表单时 NPE**：接口直接解引用空请求体
- **深色模式多处文字不可见**：`--mo-*` 刻度在暗色下被重映射为「背景/文字」两种角色，而若干规则按明色语义取了值 —— 深色块的字面色值统一令牌化，修好文章页三处深色下隐形文字、目录空状态、侧边栏选中项、主题表标签与占位符、输入框被真实 border 撑高等问题
- 字典/代码生成页补 `.catch()`，失败不再静默

## ✨ 新增与增强

- **留言板开关**（`guestbook_enabled`，默认开启）：关闭后前台三个 `/blog/message/*` 接口**读写一并拒绝**（对齐 `search_enabled` 的口径，而不是只隐藏 Vue 入口），`BlogLayout` 移除导航项，留言板页面直接渲染关闭态且不发起请求；后台审核（`/system/message`）不受开关影响
- **评论列表分页**：文章评论此前一次性加载全部，改为分页
- **分类/标签计数改 COUNT 查询**：不再全表加载后取 `size()`
- **标签总览页重设计**：改为数据驱动（不再写死标签列表），视觉现代化
- **个人中心布局重构**：从双栏工作台改为博客风格单栏标签页
- **设计系统收敛**：色板/字体/圆角/阴影令牌收敛到 `:root` 一处；前台字号与间距收敛到 `--mo-fs-*` / `--mo-sp-*` 刻度；散落的断点值统一到 768/1024；后台圆角回退为独立 px，与博客 `--mo-r-*` 解耦；抽出博客文章卡/空状态/分页/骨架屏四个公共组件，标签页与分类页改用公共组件并删除重复卡片样式；侧边栏类名去语义重载（`article-item` → `recent-item`）；删除零引用死组件 `ImagePreview`/`FileUpload` 与死代码 `LinkIcon`；支持 `prefers-reduced-motion`
- 移除导航栏右上角的源码地址与文档地址图标入口

## ⚠️ 升级提示

- **必跑数据补丁**：`sql/99_fix_blog_user_type_v1.4.3.sql`。已有安装里所有自助注册的用户 `user_type` 都是错的 `'00'`，只改代码不会修存量数据 —— 他们仍会看到「管理后台」入口。脚本只改「持有且仅持有 `blog_user` 角色」的账号，可重复执行（第二次 0 行受影响）；执行前请备份 `sys_user`/`sys_user_role`/`sys_role`
- **补丁跑完后，已注册用户需要退出重新登录**：`user_type` 在 JWT 对应的用户缓存里，旧 token 仍会返回系统用户身份
- **表结构有变更**：`blog_message` 新增 `create_by`/`update_by`。数据卷已存在的 Docker 库不会自动执行 `docker-entrypoint-initdb.d`，请手动重跑一次 `sql/00_init_database.sql`（幂等，会补列、补菜单与设置种子）
- **前后端镜像都需重建**（`user_type`、留言管理、消毒器、404、留言板开关属后端；个人中心、标签页、设计令牌、深色模式属前端产物）：`docker compose -f docker-compose.prod.yml up -d --build`
- 若要把留言板关掉，去「博客设置」里的「留言板」开关；关闭后前台接口会直接拒绝，不只是隐藏入口

**完整变更**：`git log v1.4.2..v1.4.3`
