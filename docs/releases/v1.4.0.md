# v1.4.0 (2026-09)

## ✨ 新增与增强

**内容创作**

- 文章定时发布（`publish_time` + 状态流转，到期自动发布）
- Markdown 文章：源码入库 + 服务端 flexmark 渲染 HTML 双写（支持 GFM 表格），与前端预览一致
- 自定义页面：后台单页管理（标题/别名/Markdown/SEO/导航显示/发布状态），按 `/blog/page/<别名>` 渲染
- 管理端编辑器支持富文本（Quill）与 Markdown 切换、实时预览

**读者互动与前台**

- 评论自洽：游客可直接评论/回复（昵称/邮箱生效），保留审核与 IP 限流
- 点赞体系：文章/评论点赞支持取消、按用户去重并回显状态
- 收藏与「我的收藏」列表页、前台通知铃铛（未读数轮询/已读跳转）
- 留言板 `/blog/guestbook`：匿名提交 + 图形验证码 + 输入时限（填写不足 3 秒拒绝、同一访客 60 秒一条、按钮倒计时），后台可审核/回复/删除/导出
- 友链申请：图形验证码 + 后台「显示申请入口」开关，关闭后前台隐藏、接口拒绝
- 独立搜索页、分类/标签总览页、作者主页，标签与作者名可点击
- 移动端（≤768px）汉堡菜单 + 下拉导航

**后台与统计**

- 媒体库：上传自动入库、检索与删除（联动物理文件）
- 功能开关全链路生效：统一判定口径，前台隐藏入口**且接口拒绝**；展示类开关在所有前台页面一致生效
- 每日 PV/UV 聚合（按访客去重）与近 30 天曲线；访问明细（逐条日志 + 筛选/排行/导出/清理，默认保留 90 天）
- 文章评论数与真实评论联动，并提供历史一次性重算

**SEO / 站点能力**

- 前台动态 title/description/keywords/canonical/OG，后台新增 SEO 优化页签
- `/sitemap.xml`（文章 + 静态页）与 `/robots.txt`；站点访问地址与防盗链白名单后台可管理

## 🎨 配色与可读性

- 默认主题与 mo-blog 主题在浅色/深色四种组合下逐页实测文字对比度，博客前台（13 条路由 × 811 个文本元素）与后台文章编辑器全部达到 WCAG AA
- 主按钮/分页/plain 按钮/主色文字改用按对比度推导的配对前景色；Element Plus 偏浅的 secondary/info/error 默认色另行覆盖

## 🐛 主要修复

- 分类总览页因响应字段取错（读 `rows` 而接口返回 `data`）一直显示「暂无分类」
- 深色/浅色下多处文字与背景同色（色阶误用）导致内容不可见
- 迁移脚本非幂等（分类/友链重跑重复插入）、统计假数据与失效导出、若干失效路由与权限
- 容器内 Vite 收不到宿主机文件变更导致"改了代码页面没变化"（改用轮询监听）
- 防盗链拦截返回真实 403，不再被 401 处理器包装成 HTTP 200

## 🧹 工程与质量

- 清理死代码与孤儿依赖（旧页面/组件、TinyMCE 整栈、22 个零调用 API 函数、TestController、druid 与表单构建死页面等）
- 单测与守卫测试增强（含深浅色 `--mo-*` 色阶约定、主色配对前景色的断言）

## ⚠️ 升级提示

- 已有数据库请重跑一次 `sql/00_init_database.sql`（幂等，自动补齐新表/列/菜单/权限并重算评论数）
- Docker 数据卷已存在时不会再自动执行 `docker-entrypoint-initdb.d`，必须手动重跑
- `/sitemap.xml`、`/robots.txt` 在后端根路径，Nginx 同源反代请转发到后端
