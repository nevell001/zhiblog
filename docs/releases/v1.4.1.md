# v1.4.1 (2026-09-26)

## 🔒 安全与隐私

- 上传后缀白名单移除 `html/htm`：此前任意登录用户（含自助注册的零权限账号）可上传一个同源脚本页面，再引导管理员访问即可读取非 HttpOnly 的登录 cookie；上传目录额外下发 `X-Content-Type-Options: nosniff`
- 匿名评论接口不再返回评论者邮箱：新增前台专用查询（连 email 都不从库里取）+ 响应 VO 投影（实体序列化也会带出，故做了两层）
- 前台友链列表不再返回申请者邮箱（显式字段列表，空值键也不输出）
- 客户端 IP 只采信可信代理（回环/内网）的转发头，且取 `X-Forwarded-For` 最右一跳并校验必须是 IP 字面量；nginx 由「追加」改为「覆盖」`$remote_addr`，Vite 开发代理开启 `xfwd`。此前每个请求换一个 `X-Forwarded-For` 就能绕过登录/评论/上传限流、留言冷却与浏览量去重

## 🛠 生产配置与部署

- 生产不再走「打印验证码到日志」捷径：此前 `EMAIL_DEV_PRINT_CODE` 默认为 true 且 prod 未覆盖，导致注册/找回密码收不到邮件、验证码明文进日志、`checkIpRateLimit` 整段被跳过。现在默认值改为 false、`application-prod.yml` 显式关闭，并在代码层按 profile 强制兜底
- `docker-compose.prod.yml` 的 zhi-admin 补上 `env_file: .env`（此前邮件/验证码/上传上限等变量根本进不了容器），端口改为仅绑定 `127.0.0.1:8080`（对外统一走 nginx）
- nginx 补 `client_max_body_size 20m`（默认 1MB 先于后端生效，导致 >1MB 上传直接 413），新增 `/sitemap.xml`、`/robots.txt`、`/blog/rss`、`/stage-api/` 反代（此前会被 SPA 回落成 `index.html`）

## ✨ 新增与增强

- 监控入口地址可配置：后台「博客设置 → 站点信息 → 监控入口」可分别填写 Prometheus / Grafana / Actuator 地址；留空时按「站点访问地址」自动推导（域名 + `:9090` / `:3001`，Actuator 同源 `/manage/actuator`），换域名无需重新构建前端

## 🐛 主要修复

- 友链审核语义反转：后台「通过」写入 `status=1`，而前台只展示 `status=0`，导致点「拒绝」反而公开、点「通过」反而隐藏；审核状态映射已集中到 `status.ts`，模板只传语义化动作，提示文案同步修正

## 🧪 工程与质量
