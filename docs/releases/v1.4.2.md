# v1.4.2 (2026-10-02)

本版本全部是 v1.4.1 发布之后合入的工作，主题是「注册—邮件—评论」这条自助链路能真正跑通，以及一处会让文章详情页整页打不开的回归。

## 🔒 安全与隐私

- 点赞/收藏写端点补上 IP 限流；匿名可读的设置值端点改为优先读 `blog_setting`，与后台保存的口径一致
- 验证码不再以明文进日志：日志脱敏，并且生产不再继承 dev 的 SQL 参数打印（此前注册/找回密码的验证码会随 MyBatis 参数日志落到日志文件里）
- 设置保存不再「假成功」：`sys_config` 同步失败会如实报错；后台开关切换失败给出提示并回滚 UI 状态；注册/找回密码页的倒计时定时器泄漏修复

## ✨ 新增与增强

- **邮件服务可在后台配置**：博客设置新增「邮件服务」卡片，填 SMTP 后热更新生效，不用重启容器；密码脱敏回显、留空表示不修改；支持「用当前未保存的表单直接测试连接」，并把失败原因透传到提示里（此前统一显示「连接失败」）；页面同时显示 dev-print-code 状态，「收不到信」不再无从判断
- **博客设置页改版**：功能设置按互动/账号等分组做成卡片网格，界面主题页加明暗切换
- **「用户注册」开关上设置页**：该开关真实数据源是 `sys_config.sys.account.registerUser`（默认关闭，且只认字面 `"true"`），因此新增生效值端点按注册入口的同一口径返回布尔，避免卡片显示已开启而注册仍被拒；写回仍走带 `sys_config` 镜像与缓存失效的通道
- 前台登录用户可以修改/删除自己的评论；后台评论列表加只读详情弹窗，并补全「上级分类」「标签图标」两个此前缺失的字段

## 🐛 主要修复

- **多标签文章详情页 500**：v1.4.1 的性能清理（`40ffc6e`）删掉了 `selectBlogArticleById` 的 `GROUP BY` 却留着两个标签表 `LEFT JOIN`，一行被扇成 N 行，`selectOne` 抛 `TooManyResultsException` —— 只要文章有 2 个以上标签，前台详情、后台详情、评论通知取文章全部 500（示例文章正好全中）。同一批清理一并覆盖热门文章与归档查询，并删掉从未被引用的死 `sql` 片段
- **登录用户评论「昵称不能为空」**：`SecurityContext` 补全写在了服务端校验之后，而登录态的评论表单不采集昵称，于是所有登录用户的评论都被拒。留言板存在同一处顺序缺陷，一并调整（该表单始终渲染昵称输入框，属未暴露的潜在故障）
- **示例文章数据**：种子把 Markdown 原文写进 `blog_article.content` 却让 `format` 停在默认 `'html'`，而前台详情只做消毒 + `v-html`、不渲染 Markdown，示例文章整页显示 `#`/代码围栏源码；正文改为按与后台同一套渲染器转成 HTML 后入库。同时修正关联错乱：幽灵 `tag_id=19`（表无外键，静默失效）、《Redis》挂成 MongoDB、《MySQL优化》《Vue3》《Docker》《Git》分类各挂错一处；种子里 `--retries=3 \` 被 MySQL 当转义吃掉的问题也一并处理
- 邮件依赖：`spring-boot-starter-mail` 此前是 `optional`，运行时 `NoClassDefFoundError: jakarta/mail/MessagingException`；SSL 与 STARTTLS 同时开启的冲突消解；邮件配置真正落库
- 页面浏览量统计对齐浏览开关与 24h 去重口径；友链管理进页面连刷多条「状态更新成功」；注册页卡片未居中/被导航遮挡、深色模式下标题隐形

## ⚠️ 升级提示

- 未改表结构，无需迁移脚本
- **已有安装要单独修示例文章的数据**：跑 `sql/99_fix_sample_articles_v1.4.2.sql`。`sql/00_init_database.sql` 的幂等靠 `INSERT IGNORE` 与「按标题判存在」实现，重跑只会跳过已存在的文章，不会把已是 Markdown 的正文和错挂的关联改过来。新装库不受影响（种子已修正）。补丁只按 6 个示例标题定位行、且仅在正文仍是 Markdown（`content LIKE '# %'`）时重写，你自己编辑过的文章不会被覆盖，可重复执行；跑之前先 `mysqldump` 备份 `blog_article`、`blog_article_tag`
- 后端与前端镜像都需重建（详情页 500、邮件、注册开关、留言板属后端；设置页与注册页属前端产物）：`docker compose -f docker-compose.prod.yml up -d --build`
- 邮件配置现在存在数据库里，生产仍可用 `MAIL_*` 环境变量作为初值；上线后请到「博客设置 → 邮件服务」确认一次并「测试连接」。若服务器仍在用打印验证码的捷径，注意生产默认已关闭
- 注册开关在 `sys_config` 里默认关闭，需要开放注册的实例请从「博客设置 → 功能设置 → 用户注册」打开（不要手改 SQL：`sys_config` 有 Redis 缓存，直接改库不会生效）
- 若已有文章带 2 个以上标签，升级到本版本前它们的详情页是 500 的，可用于快速判断是否命中

**完整变更**：`git log v1.4.1..v1.4.2`
